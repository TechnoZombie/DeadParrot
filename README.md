# DeadParrot

DeadParrot is a small Java-based audio "parrot" (repeater) for hobby radio use. It listens for audio, records when sound is detected, and then plays the recording back. The project provides a Swing GUI, simple settings persistence and a handful of utilities for audio device discovery and WAV handling.

Version: 2.0.0-SNAPSHOT

Highlights
- Java 21, Maven-based build
- Swing GUI (FlatLaf) for device selection and controls
- Voice-activated recording with silence detection
- Optional marker/spy modes
- Saves recordings as WAV files

Quick start
1. Build: `mvn clean package`
2. Run GUI (default): `java -jar target/deadparrot-2.0.0-SNAPSHOT.jar`
3. To run without the GUI, toggle Settings.USE_GUI to false in `src/main/java/tz/deadparrot/Settings.java` and run the JAR.

Repository layout
- src/main/java/tz/deadparrot  - application sources
- src/main/resources         - audio resources (leading ping, marker)
- deadparrot.settings       - example settings file generated by the app
- pom.xml                   - Maven build and dependencies

Notable classes
- Main.java                 - application entry (launches GUI by default)
- DeadParrotGUI.java        - Swing-based user interface and menu (Audio Tools)
- Processor.java            - coordinates startup, settings application, and shutdown
- Listener/AudioRecorder    - audio capture, silence detection and recording
- AudioPlayer/AudioMarker   - playback and marker mode
- tz.deadparrot.utils.*     - utilities (device discovery, WAV writing, settings persistence)

Defaults (from Settings.java)
- USE_GUI = true
- DEFAULT_AUDIO_FORMAT = PCM 44.1kHz, 16-bit, stereo
- SOUND_DETECTION_SENSITIVITY = 5000
- SILENCE_THRESHOLD = 500
- SILENCE_DURATION_MS = 1500
- MAX_RECORDING_TIME_MS = 60000
- KEEP_RECORDINGS = true
- SAVE_RECORDINGS_TO_DESKTOP = true
- PRINT_SETTINGS = true

Build & Development
- Requires JDK 21 and Maven
- Build: `mvn clean package`
- The shade plugin produces an executable JAR with main class `tz.deadparrot.Main`.

Dependencies (from pom.xml)
- FlatLaf (UI)
- SLF4J + Logback (logging)
- Lombok (compile-time annotations, provided scope)

Notes & troubleshooting
- If you get a "Line not supported" error, use the GUI's Audio Tools → Run Audio Probe to find supported formats.
- Check OS sound settings if no input/output devices are visible.
